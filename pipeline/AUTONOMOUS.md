# 🚀 Автономный пайплайн обработки видео кёрлинга

## ✅ Что означает "автономный"

Этот пайплайн **полностью автономен** - все необходимые модули включены в папку `pipeline` и не зависят от внешних скриптов.

### 🎯 Ключевые преимущества:

1. **Нет внешних зависимостей** - пайплайн не импортирует модули из других папок проекта
2. **Все включено** - все необходимые классы и функции находятся в папке `pipeline`
3. **Fallback методы** - если модели или конфигурация не найдены, используются альтернативные методы
4. **Портативность** - папку `pipeline` можно скопировать и использовать независимо

## 🔄 Как работает автономность

### 1. Импорты
**Было (зависимое):**
```python
from src.keypoints_detection import detect_keypoints
from src.homography import compute_homography_matrix
from src.bytetrack_tracker import track_stones_with_bytetrack
```

**Стало (автономное):**
```python
from keypoints_detector import KeypointsDetector
from homography_utils import HomographyCalculator
from stone_tracker import StoneTracker
```

### 2. Конфигурация
**Было (зависимое):**
```python
from src.config_loader import load_config
config = load_config()
```

**Стало (автономное):**
```python
from config import PipelineConfig
config = PipelineConfig()  # Автоматически находит или использует defaults
```

### 3. Fallback методы
Если модели не найдены, используются простые методы:
- **Ключевые точки**: тестовые точки для демонстрации
- **Камни**: детекция по цвету (HSV)
- **Конфигурация**: разумные значения по умолчанию

## 🎯 Преимущества автономности

1. **Простота использования** - не нужно настраивать PYTHONPATH
2. **Портативность** - можно скопировать папку и использовать где угодно
3. **Надежность** - fallback методы обеспечивают работу даже без моделей
4. **Независимость** - не зависит от изменений в других частях проекта
5. **Самодостаточность** - все необходимое включено

## 🔧 Технические детали

### Автоматический поиск ресурсов:
- **Модели**: ищет в `../models/`, `models/`, стандартных местах
- **Конфигурация**: ищет в `../configs/config.yaml`, `configs/config.yaml`
- **Видео**: ищет в `../data/videos/example_4.mp4`

### Fallback цепочка:
1. **Попытка загрузить модель** → если не найдена
2. **Использование простых методов** → если не работает
3. **Тестовые данные** → для демонстрации

### Обработка ошибок:
- Все ошибки логируются с подробным описанием
- Пайплайн продолжает работу с доступными компонентами
- Информативные сообщения о том, что используется
