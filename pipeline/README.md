# Автономный пайплайн обработки видео кёрлинга

Этот пайплайн выполняет полную обработку видео кёрлинга от обнаружения ключевых точек поля до создания визуализаций с треками камней.

**🚀 ПОЛНОСТЬЮ АВТОНОМНЫЙ** - все необходимые модули включены в папку `pipeline` и не зависят от внешних скриптов.

## Описание пайплайна

Пайплайн состоит из следующих этапов:

1. **Загрузка видео и извлечение первого кадра**
   - Загружает видео `example_4.mp4`
   - Извлекает первый кадр для анализа

2. **Обнаружение ключевых точек поля**
   - Использует обученную модель YOLO для обнаружения 22 ключевых точек поля
   - Фильтрует точки по порогу уверенности
   - Создает визуализацию найденных точек

3. **Расчет матрицы гомографии**
   - Вычисляет матрицу преобразования координат из пикселей в реальные координаты
   - Валидирует гомографию наложением реальных координат на изображение
   - Сохраняет матрицу для дальнейшего использования

4. **Обработка видео с обнаружением камней**
   - Использует модель `stones_detection_and_classification_11s.pt` для обнаружения камней
   - Классифицирует камни по цвету (красные/желтые)
   - Применяет ByteTrack трекер для отслеживания камней
   - Преобразует координаты в реальные с помощью матрицы гомографии

5. **Создание визуализаций**
   - **Видео с bbox**: оригинальное видео с наложенными bounding box для камней
   - **Bird's eye view**: анимированное видео сверху с траекториями камней

## Файлы пайплайна

### Основные скрипты:
- `curling_pipeline.py` - основной класс пайплайна
- `run_pipeline.py` - простой скрипт для запуска
- `demo.py` - демонстрационный скрипт с красивым интерфейсом
- `test_pipeline_components.py` - тестирование отдельных компонентов

### Автономные модули:
- `keypoints_detector.py` - обнаружение ключевых точек поля
- `homography_utils.py` - вычисление матрицы гомографии
- `stone_tracker.py` - обнаружение и трекинг камней
- `visualization.py` - создание визуализаций
- `config.py` - управление конфигурацией

### Документация:
- `README.md` - подробная документация
- `QUICKSTART.md` - инструкции по быстрому запуску

## Использование

### Быстрый запуск

```bash
cd curling_analytics/pipeline
python run_pipeline.py
```

### Запуск с параметрами

```bash
python curling_pipeline.py data/videos/example_4.mp4 --output-dir outputs/my_analysis
```

### Программный запуск

```python
from curling_pipeline import CurlingPipeline

pipeline = CurlingPipeline()
results = pipeline.run_full_pipeline("data/videos/example_4.mp4")
```

## Выходные файлы

После выполнения пайплайна в директории `outputs/pipeline/` будут созданы:

- `first_frame.jpg` - первый кадр видео
- `keypoints_visualization.jpg` - визуализация найденных ключевых точек
- `homography_matrix.npy` - матрица гомографии
- `homography_validation.jpg` - валидация гомографии
- `stone_tracks.json` - данные о треках камней
- `video_with_bbox.mp4` - видео с bounding box
- `birdseye_animation_with_legend.mp4` - bird's eye view анимация

## Конфигурация

Пайплайн использует автономную систему конфигурации:

- **Автоматический поиск**: ищет `configs/config.yaml` в стандартных местах
- **Конфигурация по умолчанию**: если файл не найден, используются разумные значения по умолчанию
- **Автономные модули**: все компоненты работают без внешних зависимостей

Основные параметры:
- `model_paths.keypoints_detector` - путь к модели для обнаружения ключевых точек
- `model_params.confidence_threshold` - порог уверенности для детекции
- `paths.output_dir` - директория для сохранения результатов

## Особенности

- **🚀 Полная автономность**: все модули включены в папку `pipeline`
- **🛡️ Робастность к аутлайерам**: пайплайн фильтрует ключевые точки по порогу уверенности
- **🔄 Автоматическое восстановление**: если не все 22 точки найдены, используется доступное количество
- **📊 Подробное логирование**: все этапы пайплайна логируются с прогрессом
- **✅ Валидация результатов**: гомография валидируется визуально
- **🎯 Fallback методы**: если модели не найдены, используются простые методы детекции
- **⚙️ Гибкая конфигурация**: автоматический поиск настроек с fallback на значения по умолчанию

## Устранение неполадок

1. **Ошибка "Видео файл не найден"**
   - Убедитесь, что файл `example_4.mp4` находится в `data/videos/`

2. **Ошибка "Недостаточно точек для гомографии"**
   - Проверьте качество первого кадра
   - Уменьшите порог уверенности в конфигурации

3. **Ошибка загрузки модели**
   - Проверьте пути к моделям в конфигурации
   - Убедитесь, что модели обучены и доступны
