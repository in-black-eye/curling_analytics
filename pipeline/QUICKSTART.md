# 🚀 Быстрый старт - Автономный пайплайн обработки видео кёрлинга

## Что создано

Создан **полностью автономный** пайплайн для автоматической обработки видео кёрлинга со следующими возможностями:

**🎯 КЛЮЧЕВОЕ ПРЕИМУЩЕСТВО**: Все необходимые модули включены в папку `pipeline` и не зависят от внешних скриптов!

### 📋 Основные этапы пайплайна:
1. **Загрузка видео** `example_4.mp4` и извлечение первого кадра
2. **Обнаружение ключевых точек** поля (22 точки) с помощью обученной модели YOLO
3. **Расчет матрицы гомографии** для преобразования координат из пикселей в реальные
4. **Обработка видео** с обнаружением камней и трекингом с помощью ByteTrack
5. **Создание визуализаций**:
   - Видео с bounding box поверх оригинального
   - Bird's eye view анимация с траекториями камней

## 🚀 Как запустить

### Вариант 1: Демонстрация (рекомендуется)
```bash
cd curling_analytics/pipeline
python demo.py
```

### Вариант 2: Быстрый запуск
```bash
cd curling_analytics/pipeline
python run_pipeline.py
```

### Вариант 3: С параметрами
```bash
cd curling_analytics/pipeline
python curling_pipeline.py ../data/videos/example_4.mp4 --output-dir ../outputs/my_analysis
```

## 📊 Что получите

После выполнения пайплайна в папке `outputs/pipeline/` будут созданы:

- `first_frame.jpg` - первый кадр видео
- `keypoints_visualization.jpg` - визуализация найденных ключевых точек
- `homography_matrix.npy` - матрица гомографии
- `homography_validation.jpg` - валидация гомографии
- `stone_tracks.json` - данные о треках камней
- `video_with_bbox.mp4` - видео с bounding box
- `birdseye_animation_with_legend.mp4` - bird's eye view анимация

## ⚙️ Требования

- ✅ Видео файл `example_4.mp4` в папке `data/videos/`
- ✅ Python 3.8+ с установленными зависимостями (OpenCV, NumPy, Ultralytics)
- ⚠️ Обученные модели YOLO (опционально - есть fallback методы)
- ⚠️ Конфигурация в `configs/config.yaml` (опционально - есть значения по умолчанию)

## 🔧 Особенности реализации

### 🚀 Полная автономность
- **Все модули включены** в папку `pipeline`
- **Нет внешних зависимостей** от других папок проекта
- **Автономная конфигурация** с fallback на значения по умолчанию

### 🛡️ Робастность к аутлайерам
- Пайплайн фильтрует ключевые точки по порогу уверенности
- Если не все 22 точки найдены, используется доступное количество
- Автоматическое восстановление при недостатке точек

### 🎯 Fallback методы
- **Если модели не найдены**: используются простые методы детекции по цвету
- **Если конфигурация отсутствует**: применяются разумные значения по умолчанию
- **Если ключевые точки не обнаружены**: используются тестовые точки для демонстрации

### 📊 Подробное логирование
- Все этапы пайплайна логируются с прогрессом
- Валидация результатов на каждом этапе
- Информативные сообщения об ошибках

## 🆘 Устранение проблем

### Ошибка "Видео файл не найден"
```bash
# Проверьте наличие файла
ls data/videos/example_4.mp4
```

### Ошибка "Недостаточно точек для гомографии"
- Проверьте качество первого кадра
- Уменьшите порог уверенности в конфигурации
- Убедитесь, что модель обучена корректно

### Ошибка загрузки модели
- Проверьте пути к моделям в `configs/config.yaml`
- Убедитесь, что модели обучены и доступны
