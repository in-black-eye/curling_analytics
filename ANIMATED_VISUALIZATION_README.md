# Анимированная визуализация Bird's-Eye View

## Описание

Новый модуль `src/animated_visualizations.py` позволяет создавать анимированные видео с видом сверху на поле для кёрлинга, показывающие траектории движения камней в реальном времени.

## Особенности

### Шаблон дома для кёрлинга (согласно официальным правилам)
- **Четыре концентрических круга**:
  - Внешний круг: 1,829 м (6 футов) - красный
  - 4 фута: 1,219 м - белый  
  - 2 фута: 0,610 м - синий
  - Внутренний круг: 15,24 см (6 дюймов) - белый
- **Кнопка**: центральная черная точка
- **Крест**: линии через центр для ориентации
- **Точные размеры**: соответствуют официальным правилам World Curling Federation

### Анимация
- **Пошаговая анимация**: показывает развитие игры кадр за кадром
- **Траектории камней**: прямые линии от старта до текущей позиции
- **Предыдущие позиции**: отображаются как точки соответствующего цвета
- **Текущие позиции**: камни отображаются как более крупные цветные круги
- **Прогрессивное отображение**: траектории и точки появляются по мере движения камней

### Информационная панель
- **Счетчик кадров**: показывает текущий момент времени
- **Количество камней**: отображает активные камни на поле
- **Легенда команд**: показывает цвета и количество камней каждой команды

## Использование

### В основном пайплайне

```bash
python3 experiments/run_curling_pipeline.py \
  --video data/videos/example_4.mp4 \
  --keypoints-weights outputs/runs/yolo11_boxes25/train_20251009_152028/weights/best.pt \
  --conf 0.01 \
  --video-fps 15
```

**Новые параметры:**
- `--video-fps`: FPS выходного видео (по умолчанию 15)

### Отдельное создание видео

```python
from src.animated_visualizations import create_birdseye_video_with_legend

# Создание видео с легендой
video_path = create_birdseye_video_with_legend(
    stone_tracks=stone_tracks,
    output_dir="outputs",
    fps=20,
    court_size_cm=(500, 1300),
    img_size=(800, 2080)
)
```

### Тестирование с демо-данными

```bash
python3 experiments/test_animated_visualization.py
```

## Выходные файлы

Пайплайн теперь создает два файла:
1. **`birdseye.png`** - статичное изображение со всеми траекториями
2. **`birdseye_animation_with_legend.mp4`** - анимированное видео

## Технические детали

### Координатная система
- **Ось X**: слева направо (0-500 см)
- **Ось Y**: снизу вверх (0-1300 см)
- **Дом**: расположен в верхней части поля

### Цветовая схема
- **Красная команда**: красные камни и траектории
- **Желтая команда**: желтые камни и траектории
- **Белые обводки**: для контраста камней на фоне

### Формат данных
Треки камней должны содержать:
```python
{
    "stone_id": int,
    "team": "red" | "yellow",
    "positions_real": [
        {"frame": int, "x": float, "y": float},
        ...
    ],
    "final_position_real": {"frame": int, "x": float, "y": float},
    "throw_start_frame": int,
    "throw_end_frame": int
}
```
